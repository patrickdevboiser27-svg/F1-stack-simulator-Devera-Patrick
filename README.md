Description
This project provides the starter files for a Stack Data Structure Simulator. The webpage is built with HTML, styled using CSS and Bootstrap, and driven by JavaScript with jQuery, which handles the stack’s data and how it appears on screen.

The simulator illustrates the Last In, First Out (LIFO) rule of a stack, where the most recently added item is the first one removed. The starting interface comes with four buttons: Push, Pop, Peek, and Clear.
